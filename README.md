## ⚡ Ключевые возможности

**STORM KEYS** — криптографический менеджер учётных записей, паролей, кодов двухфакторной аутентификации (`2FA / TOTP`), лицензионных ключей ПО, API-токенов, SSH/серверов, банковских карт, сетей Wi-Fi и криптокошельков на базе **Windows App SDK (WinUI 3)** и **.NET 10**.

- **Аутентифицированная криптография и многофакторная защита сейфа**: сквозное шифрование **AES-256-GCM** (с проверкой 128-битного тега целостности `MAC`), деривация мастер-ключа через **Argon2id** (`64 МБ`, `4` итерации, `4` потока), аппаратный **Ключ-файл (`.stormkey` 2FA)**, **Пароль под принуждением (`Duress Password` — Ложный сейф)** и **Анти-скриншот щит (`WDA_EXCLUDEFROMCAPTURE`)** против перехвата экрана в OBS, Discord, Zoom и скриншотерах.
- **Биометрическая разблокировка Windows Hello (Поверх всех окон)**: мгновенный вход в хранилище по отпечатку пальца, сканеру лица `Windows Hello Face` или системному PIN-коду через `IUserConsentVerifierInterop` (с автоматическим выводом диалога поверх окна программы) и бесшовную DPAPI-синхронизацию мастер-пароля.
- **Встроенный аутентификатор 2FA (`TOTP RFC 6238`) + QR-матрица**:
  - Поддержка сырых ключей `Base32`, полных URI `otpauth://totp/...` и **умного сканера 2FA из буфера обмена**.
  - Живой 30-секундный таймер с **умным ожиданием нового кода (`Smart TOTP Wait`)** при остатке `≤ 3 сек.`, генератор **2D QR-матрицы** для переноса 2FA на смартфон и встроенный **сейф резервных кодов восстановления 2FA**.
- **Интерактивный Центр аудита безопасности и проверка утечек (`Have I Been Pwned API`)**: сводный отчёт уязвимостей хранилища, конфиденциальная проверка по протоколу **k-Anonymity**, фильтр устаревших паролей (`> 180 дней`) и кнопка **автоматической пакетной замены слабых/дублирующихся паролей в 1 клик**.
- **Настраиваемые макросы авто-ввода (`Auto-Type`), Авто-матчер активного окна и Drag & Drop**:
  - Автоматическое распознавание предыдущего активного окна браузера, игры, терминала или приложения с мгновенным баннером авто-входа в шапке программы.
  - Настраиваемые шаблоны макросов (`{USER}{TAB}{PASS}{ENTER}`, `{USER}{TAB}{PASS}{TAB}{TOTP}{ENTER}`, `{DELAY 1000}`) и перетаскивание (`Drag & Drop`) логина, пароля или 2FA-кода мышью прямо в поля ввода.
- **9 форматов данных, вложения до 2 МБ, Банковские карты и Wi-Fi в 1 клик**:
  - Шаблоны: **Сайт / Аккаунт**, **Лицензия ПО / Игры**, **API Ключ / Токен**, **SSH / Сертификат**, **Сервер / БД / RDP**, **Банковская карта** (быстрые кнопки `CVV`, `Срок`, `PIN`), **Сеть Wi-Fi** (генерация `QR Wi-Fi` для телефона и подключение ПК в 1 клик через `netsh wlan`), **Крипто / Seed-фраза**, **Заметка / PIN**.
  - Прикрепление **зашифрованных файловых вложений** (`.pem`, `.ppk`, `.ovpn`, `.pfx`, `.cer`, `.key` до `2 МБ`) прямо внутрь контейнера `.stormdb`.
- **Привязка к локальным программам (`.exe`) и сайтам (`URL`)**: выбор исполняемого файла (`.exe`, `.lnk`, `.rdp`, `.bat`) или веб-адреса (`https://`, `ssh://`, `rdp://`) с кнопкой запуска приложения или открытия сайта в 1 клик прямо с карточки.
- **Параметрический генератор паролей и API-токенов разработчика**:
  - Настраиваемая длина (`6–64` символа, пресеты `12 / 16 / 24 / 32 / 48`), выбор классов символов (`A–Z`, `a–z`, `0–9`, `!@#$%^&*`), фильтр похожих символов (`0/O, 1/l`).
  - Генерация **Криптостойких паролей**, **Мнемонических фраз (`Diceware`)**, **Лицензионных ключей ПО**, **PIN-кодов** и **API-токенов разработчика** (`256-bit HEX`, `JWT Secret Base64`, `UUID v4`, `Bearer sk_live_...`, `SSH Fingerprint`).
- **Корзина удалённых записей, слоты `.bak1..3` и зашифрованный архив `.stormbackup`**:
  - Безопасная **Корзина** с хранением удалённых записей до 30 дней и восстановлением в 1 клик.
  - Откат к любому из 3 поколений резервных копий (`.bak1`, `.bak2`, `.bak3`) прямо из настроек, экспорт/импорт зашифрованных архивов **`.stormbackup`**, выгрузка в **`.env`** и импорт из **KeePass 2.x (`.xml`)** и **Kaspersky Password Manager (`.txt`)**.

## ⌨️ Инструкция по работе и горячие клавиши

### Способы добавления записей:
1. **Вручную по шаблону (`Ctrl+N`)**: нажмите кнопку **«+ Добавить»** в верхней панели или выберите шаблон на стартовой панели, укажите категорию, иконку, сгенерируйте пароль или API-токен и при необходимости добавьте `2FA` и вложения.
2. **Умная вставка из буфера (`Ctrl+V`)**: скопируйте строку `Логин:Пароль`, `https://user:pass@site.com`, переменную `.env`, 25-значный ключ ПО или ссылку `otpauth://totp/...` и нажмите **«📋 Вставить»** (либо кнопку **«Из буфера»** внутри окна редактирования).
3. **Пакетный импорт (`CSV / JSON / XML / .env / .txt / .stormbackup`)**: используйте меню **«Импорт»** или перетащите файл мышью (`Drag & Drop`) прямо в окно программы (поддерживаются экспорты Google Chrome, Microsoft Edge, Firefox, Bitwarden, KeePass 2.x XML, Kaspersky Password Manager).

### Горячие клавиши (Локальные и Глобальные):
| Сочетание | Действие |
| :--- | :--- |
| **`Ctrl + Shift + Space`** | **Глобальный Spotlight-вызов**: развернуть окно `STORM KEYS` поверх всех окон с фокусом в строке поиска (по `Enter` — авто-ввод первой найденной записи) |
| **`Ctrl + Shift + L`** | **Глобальная экстренная блокировка (`Panic Lock`)**: мгновенно заблокировать сейф, очистить буфер обмена и свернуть окно в трей |

| **`Ctrl + V`** | Быстрый импорт записи из буфера обмена |

## 🛡️ Архитектура безопасности и хранения

1. **Контейнер `.stormdb`**: содержит сигнатуру `STORMDB1`, 16-байтную соль `Argon2id`, 12-байтный вектор инициализации (`Nonce`) и 16-байтный тег аутентификации `AES-256-GCM`. Любое изменение байтов файла обнаруживается до расшифровки.
2. **Защита буфера обмена и памяти**: скопированные пароли и секреты автоматически очищаются из системного буфера обмена по таймеру; просмотр секрета на карточке (**Inline Peek**) автоматически скрывается через 5 секунд; при неактивности срабатывает таймер автоблокировки.
3. **Гибридная синхронизация**: атомарное локальное сохранение сочетается с бесконфликтным слиянием записей по временным меткам при подключении облачной папки (`OneDrive`, `Google Drive`, `WebDAV`, сетевой диск).

## 💻 Установка и сборка

### Установка из готового дистрибутива:
1. Запустите автономный установщик из папки `Files/` или секции **Assets** релиза.
2. Подтвердите запрос контроля учётных записей (UAC), выберите стандартный режим (`C:\Program Files\STORM KEYS`) или портативный режим (`.portable`) и нажмите **«⚡ Установить»**.

### Сборка из исходного кода:
- **Требования**: Windows 10 (1809+) или Windows 11 (x64), `.NET 10 SDK`.
```powershell
# Запуск автоматического набора из 26 модульных тестов
dotnet run --project tests/StormKeys.Tests -c Release

# Сборка и публикация автономного приложения
dotnet publish StormKeys.csproj -c Release -r win-x64 --self-contained true -o "./publish"

# Сборка автономного однофайлового установщика
dotnet publish installer/StormKeys.Installer.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o "./Files"
```
