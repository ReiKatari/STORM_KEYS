## ⚡ Описание

**STORM KEYS** — архитектурный менеджер учётных записей, паролей и лицензий программного обеспечения, построенный на базе современных технологий **Windows App SDK (WinUI 3)** и криптографических стандартов нового поколения.

Приложение спроектировано в строгом соответствии с дизайн-системой **STORM AURORA FLUID** и общими стандартами экосистемы приложений STORM:
- **Криптографическая защита**: симметричное шифрование **AES-256-GCM** с аутентификацией данных и производством ключей через **Argon2id** (память: 64 МБ, 4 итерации, 4 параллельных потока, уникальная криптографическая соль 16 байт).
- **Контроль сроков действия**: цветовая индикация и автоматические системные уведомления Windows о приближающемся окончании действия лицензий и паролей (за 30, 7 и 1 день).
- **Гибридное хранилище**: локальный зашифрованный контейнер (`.stormdb`) с возможностью автоматической зеркальной синхронизации с облачными папками (OneDrive, Google Drive, Яндекс Диск, WebDAV, сетевые шары).
- **Легитимный импорт**: встроенный мастер миграции учётных записей из экспортированных файлов CSV и JSON (Google Chrome, Edge, Firefox, Bitwarden, KeePass) и буфера обмена без фонового перехвата данных браузеров.
- **Интеграция с Windows**: сворачивание в системный трей (**Close-to-Tray / Exit-Only-from-Tray**), стилизованные всплывающие подсказки (**TeachingTip / Flyout**) и поддержка генерации сложных паролей и лицензий.
- **Единый тёмный установщик**: сборка с манифестом `requireAdministrator`, цифровой подписью доверенного издателя **STORM TEAM** и установкой в `C:\Program Files\STORM KEYS`.
- **Автономность**: 100% self-contained исполнение без необходимости установки внешних пакетов MSIX или Windows App Runtime.
- **Автоматическое обновление**: встроенная система проверки и фоновой установки обновлений релизов GitHub.

## 🛡️ Безопасность и архитектура данных

Хранилище STORM KEYS сохраняет данные в атомарном зашифрованном файле `.stormdb`:
1. **Заголовок**: сигнатура `STORMDB1`, 16-байтовая криптографическая соль Argon2id, 12-байтовый одноразовый вектор инициализации (IV / Nonce) и 16-байтовый тег аутентификации AES-GCM.
2. **Аутентифицированный шифротекст**: сериализованный JSON-контейнер записей шифруется ключом AES-256. Любая попытка модификации или повреждения файла выявляется мгновенно до расшифровки.
3. **Безопасность в оперативной памяти**: пароли и секретные ключи очищаются в памяти при блокировке; предусмотрен таймер автоматической блокировки при бездействии.

## 💻 Установка и запуск

1. Запустите инсталлятор `STORM_KEYS_<VERSION>_Setup.exe` из папки `Files/`.
2. В окне контроля учётных записей Windows (UAC) убедитесь в наличии синего доверенного щита и строки:
   - **Проверенный издатель**: `STORM TEAM`
   - **Программа**: `STORM KEYS`
3. Выберите режим (стандартный в `C:\Program Files\STORM KEYS` или портативный) и нажмите **«⚡ Установить»**.
4. При первом запуске задайте надёжный мастер-пароль для создания зашифрованного контейнера.

## 📦 Сборка из исходного кода

### Требования:
- Windows 10 (версия 1809+) или Windows 11
- .NET 10 SDK
- Windows App SDK / WinUI 3

### Команды сборки:

```powershell
# Сборка автономного приложения
dotnet build StormKeys.csproj -c Release -r win-x64

# Публикация автономной сборки
dotnet publish StormKeys.csproj -c Release -r win-x64 -p:PublishProfile=win-x64 -o "./publish/win-x64"

# Сборка установщика
dotnet publish installer/StormKeys.Installer.csproj -c Release -r win-x64 --self-contained true -o "./dist"
```
