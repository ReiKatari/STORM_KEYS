## ⚡ Ключевые возможности

**STORM KEYS** — криптографический менеджер учётных записей, паролей, кодов двухфакторной аутентификации (`2FA / TOTP`), лицензионных ключей ПО, API-токенов, SSH/серверов, банковских карт, сетей Wi-Fi и криптокошельков на базе **Windows App SDK (WinUI 3)** и **.NET 10**.

- **Аутентифицированная криптография**: сквозное шифрование **AES-256-GCM** (с проверкой 128-битного тега целостности `MAC`) и деривация мастер-ключа через **Argon2id** (память `64 МБ`, `4` итерации, `4` потока, уникальная 16-байтная криптостойкая соль).
- **Биометрическая разблокировка Windows Hello**: мгновенный вход в хранилище по отпечатку пальца, сканеру лица `Windows Hello Face` или системному PIN-коду через `KeyCredentialManager` и аппаратную защиту `Windows DPAPI`.
- **Встроенный аутентификатор 2FA (`TOTP RFC 6238`)**:
  - Поддержка как сырых ключей `Base32`, так и полных URI `otpauth://totp/...` из QR-кодов (с автоматическим извлечением сервиса и аккаунта).
  - Живой 30-секундный таймер и генерация 6-значных кодов (`XXX XXX`) как на карточках, так и прямо внутри окна создания записи для мгновенного подтверждения привязки 2FA на сайтах.
- **Аудит утечек паролей (`Have I Been Pwned API`)**: конфиденциальная проверка отдельных записей и пакетный аудит всего хранилища по протоколу **k-Anonymity** (передаётся только 5-символьный префикс `SHA-1` хэша; пароли никогда не покидают устройство).
- **Быстрый автоввод (`Auto-Type` через Win32 `SendInput`)**: печать `Логин + Tab + Пароль + Enter` (или 6-значного кода `2FA`) напрямую в предыдущее активное окно браузера, игры, лаунчера, терминала или RDP-клиента с одновременным копированием 2FA в буфер обмена.
- **9 форматов данных, готовые шаблоны и 20 иконок**:
  - Шаблоны в 1 клик: **Сайт / Аккаунт**, **Лицензия ПО / Игры**, **API Ключ / Токен**, **SSH / Сертификат**, **Сервер / БД / RDP**, **Банковская карта**, **Сеть Wi-Fi**, **Крипто / Seed-фраза**, **Заметка / PIN**.
  - Палитра из **20 семантических иконок**, система `#тегов` и неограниченные дополнительные поля `Ключ: Значение` (`PIN`, `CVV`, `Port`, `Seed`).
- **Привязка к локальным программам (`.exe`) и сайтам (`URL`)**: выбор исполняемого файла (`.exe`, `.lnk`, `.rdp`, `.bat`) или веб-адреса (`https://`, `ssh://`, `rdp://`) с кнопкой запуска приложения или открытия сайта в 1 клик прямо с карточки.
- **Параметрический генератор секретов и оценка стойкости**:
  - Настраиваемая длина (`6–64` символа, пресеты `12 / 16 / 24 / 32 / 48`), выбор классов символов (`A–Z`, `a–z`, `0–9`, `!@#$%^&*`), фильтр похожих символов (`0/O, 1/l`).
  - Четыре режима генерации: **Криптостойкий пароль** (`Fisher-Yates`), **Мнемоническая парольная фраза** (`Diceware / xkcd`), **Лицензионный ключ ПО** (`XXXXX-XXXXX-...`) и **PIN-код**.
  - Живой расчёт информационной энтропии в битах (`H = L × log₂(N)`) и оценка времени перебора на GPU-кластерах.
- **Контроль сроков действия и индекс безопасности**: живая шкала здоровья хранилища, быстрые чипы фильтрации (`Все`, `Избранное`, категории, `В утечках`, `Слабые`, `Дубликаты`, `Истекающие`) и фоновые системные уведомления Windows (`Toast Notifications`) за `30`, `7` и `1` день до истечения срока.
- **Журнал истории паролей, резервные копии и аварийный лист**:
  - Автоматическое сохранение до 5 предыдущих паролей в каждой записи с возможностью восстановления в 1 клик.
  - Цепочка из 3 поколений автоматических резервных копий (`.bak1`, `.bak2`, `.bak3`), создание ручных снапшотов, смена мастер-пароля «на лету» и выгрузка печатного **Аварийного листа восстановления (`.txt`)**.

## ⌨️ Инструкция по работе и горячие клавиши

### Способы добавления записей:
1. **Вручную по шаблону (`Ctrl+N`)**: нажмите кнопку **«+ Добавить»** в верхней панели или выберите шаблон на стартовой панели, укажите категорию, иконку, сгенерируйте пароль и при необходимости вставьте секрет `2FA`.
2. **Умная вставка из буфера (`Ctrl+V`)**: скопируйте строку `Логин:Пароль`, `https://user:pass@site.com`, переменную `.env`, 25-значный ключ ПО или ссылку `otpauth://totp/...` и нажмите **«📋 Вставить»** (либо кнопку **«Из буфера»** внутри окна редактирования).
3. **Пакетный импорт (`CSV / JSON / .env / .txt`)**: используйте меню **«Импорт»** или перетащите файл мышью (`Drag & Drop`) прямо в окно программы (поддерживаются экспорты Google Chrome, Microsoft Edge, Firefox, Bitwarden, KeePass).

### Горячие клавиши:
| Сочетание | Действие |
| :--- | :--- |
| **`Ctrl + N`** | Открыть окно создания новой записи |
| **`Ctrl + F`** | Установить фокус в строку умного поиска (по словам и `#тегам`) |
| **`Ctrl + V`** | Быстрый импорт записи из буфера обмена |
| **`Ctrl + D`** | Дублировать (клонировать) выбранную запись |
| **`Ctrl + Z`** | Отменить удаление последней удалённой карточки (`Undo`) |
| **`Ctrl + L`** | Немедленно заблокировать хранилище и очистить ключи в памяти |
| **`ESC`** | Закрыть любое открытое модальное окно, подсказку или меню |

## 🛡️ Архитектура безопасности и хранения

1. **Контейнер `.stormdb`**: содержит сигнатуру `STORMDB1`, 16-байтную соль `Argon2id`, 12-байтный вектор инициализации (`Nonce`) и 16-байтный тег аутентификации `AES-256-GCM`. Любое изменение байтов файла обнаруживается до расшифровки.
2. **Защита буфера обмена и памяти**: скопированные пароли и секреты автоматически очищаются из системного буфера обмена по таймеру; просмотр секрета на карточке (**Inline Peek**) автоматически скрывается через 5 секунд; при неактивности срабатывает таймер автоблокировки.
3. **Гибридная синхронизация**: атомарное локальное сохранение сочетается с бесконфликтным слиянием записей по временным меткам при подключении облачной папки (`OneDrive`, `Google Drive`, `WebDAV`, сетевой диск).

## 💻 Установка и сборка

### Установка из готового дистрибутива:
1. Запустите автономный установщик из папки `Files/` или секции **Assets** релиза.
2. Подтвердите запрос контроля учётных записей (UAC), выберите стандартный режим (`C:\Program Files\STORM KEYS`) или портативный режим (`.portable`) и нажмите **«⚡ Установить»**.

### Сборка из исходного кода:
- **Требования**: Windows 10 (1809+) или Windows 11 (x64), `.NET 10 SDK`.
```powershell
# Запуск автоматического набора из 26 модульных тестов
dotnet run --project tests/StormKeys.Tests -c Release

# Сборка и публикация автономного приложения
dotnet publish StormKeys.csproj -c Release -r win-x64 --self-contained true -o "./publish"

# Сборка автономного однофайлового установщика
dotnet publish installer/StormKeys.Installer.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o "./Files"
```
